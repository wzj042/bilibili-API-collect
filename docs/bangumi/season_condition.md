# 剧集索引筛选条件

## 获取索引筛选条件

> https://api.bilibili.com/pgc/season/index/condition

*请求方式：GET*

返回指定剧集类别的筛选维度、选项名称与参数值，以及可选排序方式。将 `filter[].field` 作为参数名、所选 `values[].keyword` 作为参数值，传入 [获取剧集索引](season_index.md) 接口。

2026-10-29（Asia/Hong_Kong）实测：番剧、电影、纪录片、电视剧均可在浏览器中使用 `credentials: 'omit'` 获取配置，未携带 Cookie 或 WBI 签名。配置与各索引页 `__INITIAL_STATE__.filters/orders` 逐项一致。本次浏览器网络记录未观察到页面直接调用此配置接口；它是独立请求验证的接口，不应把服务端注入的页面配置误记为浏览器 XHR。

**URL 参数：**

| 参数名 | 类型 | 内容 | 必要性 | 备注 |
| --- | --- | --- | --- | --- |
| season_type | number | 剧集类别 | 必要 | 番剧 `1`、电影 `2`、纪录片 `3`、电视剧 `5`；本次核实这四类 |
| type | number | （？） | 必要 | 实测传 `1`；电影类别省略时返回 `code=-400`，其他取值含义未验证 |

国创 `4`、综艺 `7` 是现有索引文档列出的类别，本次未复核其配置，不将下方枚举套用到这两类。

**JSON 回复：**

根对象：

| 字段 | 类型 | 内容 | 备注 |
| --- | --- | --- | --- |
| code | number | 返回值 | `0`：成功；`-400`：请求错误（省略 `type` 时实测） |
| message | string | 返回消息 | 先检查 `code`，不能仅以 HTTP 200 判定成功 |
| data | object | 筛选配置 | |

`data` 对象：

| 字段 | 类型 | 内容 | 备注 |
| --- | --- | --- | --- |
| filter | array | 筛选维度列表 | 各频道的维度、选项及顺序可能不同 |
| order | array | 排序方式列表 | 用于生成 `order` 和 `sort` 参数 |

`filter` 数组中的对象：

| 字段 | 类型 | 内容 | 备注 |
| --- | --- | --- | --- |
| field | string | 查询参数名 | 如 `style_id`、`producer_id`、`year` |
| name | string | 筛选维度名称 | 如“风格”“出品”“年份” |
| values | array | 可选值列表 | |

`values` 数组中的对象：

| 字段 | 类型 | 内容 | 备注 |
| --- | --- | --- | --- |
| keyword | string | 请求参数值 | 按原字符串传递；可能为单值、逗号分隔的组合值或时间区间；`-1` 为全部 |
| name | string | 选项显示名称 | 不要直接把中文名称作为参数值 |

`order` 数组中的对象：

| 字段 | 类型 | 内容 | 备注 |
| --- | --- | --- | --- |
| field | string | 排序指标值 | 传给列表接口的 `order` 参数 |
| name | string | 排序名称 | 如“播放数量”“追番人数” |
| sort | string | 页面提供的排序方向 | `0`：降序；`1`：升序；`0,1` 表示两种方向均提供，实际请求只传一个值 |

**示例：**

获取电影索引筛选配置：

```shell
curl -G 'https://api.bilibili.com/pgc/season/index/condition' \
  --data-urlencode 'season_type=2' \
  --data-urlencode 'type=1'
```

## 频道与筛选维度

| 索引页 | season_type | 筛选参数 |
| --- | --- | --- |
| [电影](https://www.bilibili.com/movie/index/) | 2 | `area`、`style_id`、`release_date`、`season_status` |
| [纪录片](https://www.bilibili.com/documentary/index/) | 3 | `style_id`、`producer_id`、`release_date`、`season_status` |
| [电视剧](https://www.bilibili.com/tv/index/) | 5 | `area`、`style_id`、`release_date`、`season_status` |
| [番剧](https://www.bilibili.com/anime/index/) | 1 | `season_version`、`spoken_language_type`、`area`、`is_finish`、`copyright`、`season_status`、`season_month`、`year`、`style_id` |

频道首页只展示部分入口，索引页及配置接口提供更完整的选项。`#st=...&style_id=...` 是页面 URL 的片段，由前端解析，不会直接发送给 HTTP 服务端；调用 API 时应使用查询参数及明确的 `season_type`。

## 验证记录

完整配置和查询摘要见 [实测数据](../../examples/bangumi-index/filter-audit.json)。本次未保存 Cookie、用户信息或设备指纹。

- 四频道配置的名称、参数值、顺序和排序配置均与索引页一致。
- 四频道列表在不携带 Cookie 的情况下重放成功，首页 `season_id` 序列与抓包一致。
- 电影“科幻 + 中国港台 + 最高评分”返回 13 项；电视剧“其他风格 + 中国”返回 221 项。
- 纪录片“电影”返回 103 项，“BBC”返回 684 项；两者组合返回 0 项，业务码仍为 `0`。空列表是有效查询结果，不应当成请求失败。
- 番剧“电影 + 中文配音 + 年份区间”成功返回列表。接口接受组合参数不代表逐部作品的语义归类已人工核验。
- 电影科幻列表第 2 页返回 `num=2`、`size=20`、`has_next=1`。数量随内容上下架变化，仅用于记录本次观察。
